Qué estamos controlando

Con sampling activado, el modelo elige el siguiente token de una distribución. La temperatura modifica esa distribución antes del muestreo.

Para logits zᵢ, la probabilidad es proporcional a exp(zᵢ / T). Cuando T < 1, las diferencias se amplifican. Cuando T > 1, la distribución se aplana.

Con sampling desactivado, esta demostración usa generación greedy: se selecciona sistemáticamente el token de mayor puntuación.
